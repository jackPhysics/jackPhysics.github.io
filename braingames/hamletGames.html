'Hamlet'

Heard of 'Othello', the commercial name for Reversi?
Well 'Hamlet' is a puzzle game of my own invention based on Reversi.
The aim is to change the whole board into a single colour - should you change 2B? or not? That's the question... it's so hard to make the decision...
You can try with 2 to 5 colours, vary the tile flip rules, and most crucially, vary the 'colour choose' rules - that has the biggest effect on game play I think.
Does it work as a puzzle? Is it too easy or too hard? Hamlet himself would not be able to decide.

RULES: The aim is to make the whole board a single colour.
Clicking a square changes it to the current colour (shown at the top left).
You cannot change a square to the colour it already is and you cannot change a square two turns consecutively.
When you change a square to a new colour any squares trapped between it and any other squares of the same colour will be flipped to that colour.
If you are using more than 2 colours then all the intermediate, trapped, squares need to be of the exact same colour in order to be flipped.

IMPORTANT NOTE: the colours are chosen at semi-random, there is some attempt to avoid similar colours, but sometimes this does not work, particularly with shades of white - which all tend to look 'white'...
So, everytime you start a game, check the range of colours chosen at the top of the page to ensure you can tell the difference - if not refresh and start again.
